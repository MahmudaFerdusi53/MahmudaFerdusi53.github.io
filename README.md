# Mahmuda Ferdusi — EdTech Portfolio

Static personal portfolio for Mahmuda Ferdusi, focused on Educational Technology & Engineering, learning design, research, curriculum, NLP, training, and community engagement.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- No framework
- No build step
- No API keys

## GitHub Pages

Publish directly from the `main` branch and repository root:

**Settings → Pages → Deploy from a branch → main → /(root)**
